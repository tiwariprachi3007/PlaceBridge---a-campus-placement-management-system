Optional: to get the exact typography of the web prototype, drop these font files here
(.ttf or .otf) and restart the app. PlaceBridge loads everything in this folder at start-up.

  Fraunces            (headings)   https://fonts.google.com/specimen/Fraunces
  Plus Jakarta Sans   (body text)  https://fonts.google.com/specimen/Plus+Jakarta+Sans

Without them the app falls back to Georgia / Segoe UI automatically.
